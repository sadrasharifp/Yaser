# IMU Earth-Rate Baseline and Synthetic Noise Pipeline

This repository contains a two-stage data processing pipeline designed to prepare high-fidelity, physically constrained inertial measurement unit (IMU) datasets for neural network training. 

The pipeline mathematically isolates true sensor noise from the Earth's DC rotation rate, generates statistically robust synthetic noise via Frequency Domain Modeling (FDM), and outputs windowed `.npy` tensors split into `train` and `test` sets.

---

## Workflow Overview

The pipeline strictly follows a two-step execution order:
1. **Module 1 (`generate_earth_rate_dataset.py`):** Ingests raw IMU CSVs, performs accelerometer leveling, and calculates the exact theoretical Earth rotation vector for each axis. 
2. **Module 2 (`Add_Noise_and_preprocess_3.py`):** Ingests the output from Module 1, isolates the bias/noise by subtracting the physical Earth rate, calculates a robust Power Spectral Density (PSD), generates synthetic noise, and chunks the data into training-ready `.npy` windows.

---

## Module 1: Earth-Rate Physical Baseline Generator
**File:** `generate_earth_rate_dataset.py`

This script projects the theoretical Earth rotation rate onto the 3D body axes of the gyroscope. It accounts for the local latitude and uses the accelerometer readings to level the platform (calculating roll and pitch) to ensure the physical target vector is mathematically perfect.

### Inputs & Directory Structure
*   **Raw CSVs:** Must contain columns `time`, `W_x`, `W_y`, `W_z`, `A_x`, `A_y`, `A_z`.
*   **Filename Convention:** The script extracts the ground-truth heading angle from the filename (e.g., `Psi_045.csv` -> 45°).
*   **`stat.txt`:** A text file in the root dataset directory containing the local latitude (e.g., `lat:35.727`).

### Outputs
Creates a new directory (`earth_rate_baselines`) containing CSVs with three newly appended columns:
*   `earth_rate_x`, `earth_rate_y`, `earth_rate_z`

### Key Configuration
Modify the `main()` execution block to match your directories:
```python
csv_folder = r"Path\To\Raw\Dataset"
output_folder = r"Path\To\Dataset\earth_rate_baselines"
stat_file = r"Path\To\Dataset\stat.txt"
fs = 2000.0  # Raw sampling rate in Hz
axis_order = (0, 2, 1)  # Permutation for local Z-up frame
```

## Module 2: Unified Stationary PSD Noise Pipeline
**File:** `Add_Noise_and_preprocess_3.py`

This script handles resampling, localized PSD evaluation, synthetic noise generation, and tensor formatting. It utilizes an adaptive 4-segment Welch's method to calculate the PSD, ensuring robust frequency-domain analysis regardless of the chosen window length. Crucially, it subtracts the theoretical Earth rate (from Module 1) before calculating the PSD to preserve the true bias instability interval.

### Inputs
*   The `earth_rate_baselines` directory generated by Module 1.

### Outputs
Creates a target directory (e.g., `Stationary_NPY`) containing:
*   **`train/` and `test/` folders:** Contain subdirectories for `clean`, `noisy`, and `earth` `.npy` tensors.
*   **`stats.json` & `splits.json`:** Normalization scalars (mean/std) and dataset split tracking.
*   **`index_train.csv` & `index_test.csv`:** Lookup tables tracking the exact position, heading, and Earth rate for every window.
*   **`diagnostic_psd_evaluation.png`:** A 9-panel diagnostic plot validating the synthetic noise generation against the raw data.

### Key Configuration
Modify the `main()` block to configure the deep learning window parameters:
```python
csv_folder = r"Path\To\Dataset\earth_rate_baselines"
output_dir = r"Path\To\Stationary_NPY"
fs = 100.0             # Neural network target frequency
window_len = 3000      # Size of the sequence length (e.g., 30 seconds)
hop_len = 1500         # 50% overlap for smooth inference reconstruction
train_frac = 0.70      # 70% Train / 30% Test split
```

## Execution Guide

To successfully generate the training dataset, execute the scripts sequentially:

**Step 1: Generate the Physical Baselines**
Verify your directory paths in `generate_earth_rate_dataset.py` and run the script.
```bash
python generate_earth_rate_dataset.py
```
*Wait for the console to output `Successfully generated baseline datasets!`*

**Step 2: Generate the Synthetic Noise Tensors**
Ensure the `csv_folder` path in `Add_Noise_and_preprocess_3.py` points to the output of Step 1.
```bash
python Add_Noise_and_preprocess_3.py
```
*Note: If you are changing the `window_len` parameter, you must delete the existing `Stationary_NPY` directory before re-running Step 2 to prevent tensor shape mismatches.*

### Diagnostic Verification
After Step 2 completes, open `diagnostic_psd_evaluation.png`. 
*   Check the **Power Spectral Density** panels (middle column). The synthetic noise (orange dashed line) should closely track the raw signal (blue solid line). 
*   This confirms the FDM process successfully modeled the unique bias instability and Angle Random Walk of your sensor.
